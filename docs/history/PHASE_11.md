# OwBrand Phase 11 — Customer Experience & Application Shell

Phase 11 builds the customer-facing structure around the golden path.

## Primary navigation

Dashboard
→ Brand Brain
→ Products
→ Creative Studio
→ Campaigns
→ Content Calendar
→ Approval Inbox
→ Social Accounts
→ Analytics
→ AI Recommendations
→ Team
→ Billing
→ Settings
→ Help & Support

## Onboarding

The first-run experience guides the customer through:

1. Workspace
2. Brand Brain
3. First product
4. Product photos
5. Social connections
6. First campaign
7. First scheduled content

The application should show progress and always provide a clear next action.

## UX state standard

Every major screen must support:

- loading
- empty
- success
- error
- retry
- permission denied
- plan/usage limit reached
- disconnected integration
- unsaved changes
- destructive-action confirmation

## Core dashboard

The dashboard should answer five questions immediately:

1. What is my brand doing?
2. What is scheduled?
3. What needs my approval?
4. How are my campaigns performing?
5. What should OwBrand do next?

Recommended dashboard cards:

- Brand health
- Upcoming posts
- Approval queue
- Content generated this period
- Engagement
- Reach
- Conversions/revenue when available
- Top-performing content
- AI recommendations
- Usage/credits
- Connected account health

## Creative Studio

The Creative Studio should expose:

- upload normal product images
- background replacement
- scene selection
- product-shot generation
- lifestyle compositions
- aspect-ratio variants
- social-ready crops
- image enhancement
- short-form video generation
- reel/ad concepts
- copy/caption generation
- version comparison
- approval

The UI must clearly label AI-generated media and preserve the original source asset.

## Campaign wizard

A campaign should be created through:

Goal
→ audience
→ products
→ offer
→ platforms
→ content mix
→ budget (optional)
→ schedule
→ automation level
→ review
→ launch

## Approval inbox

Users should see:
- asset preview
- caption
- target platform
- scheduled time
- campaign
- AI rationale
- source product
- approve
- reject
- request edit

## Responsive design

Mobile should prioritize:
Dashboard → Approvals → Calendar → Notifications.

Desktop can expose the full sidebar and multi-column analytics/creative workflows.
