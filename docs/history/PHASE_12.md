# OwBrand Phase 12 — Premium Design System & Reusable UI

Phase 12 establishes one consistent visual language for the entire product.

## Design principles

### 1. Premium but practical
OwBrand should feel like a serious AI business operating system, not a generic AI dashboard.

### 2. Content first
Large product visuals, campaign previews and useful metrics should receive more visual priority than decoration.

### 3. Clear hierarchy
Every screen should have:
- one primary action
- obvious secondary actions
- concise supporting information
- clear status

### 4. Progressive disclosure
Advanced automation settings should not overwhelm new users. Keep common actions simple and reveal advanced controls when needed.

## Accessibility

The system includes keyboard navigation, visible focus, semantic labels, reduced-motion support, meaningful image alternatives, form error association and non-color-only status communication.

## Responsive behavior

Desktop:
full navigation + multi-column workflows.

Tablet:
collapsible navigation + two-column content.

Mobile:
bottom/compact navigation patterns where appropriate, full-screen creative previews, stacked analytics and one-handed primary actions.
